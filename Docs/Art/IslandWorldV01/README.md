# 全岛探索路线

试玩场景为 [Island_World_V01.unity](../../../Assets/Scenes/Island_World_V01.unity)。八区与道路以 [本轮规划参考图](../Standards/Island_Exploration_Routes_Reference.png) 为准。按已有岛屿轮廓和地标位置调整。

- 主路从沉船海滩出发，经椰林海岸、西部森林、中央草地木桥、东部林缘和北部岩石山地，到达东北灯塔崖。
- 在木桥东侧分岔，沿河东岸到达南部河口停留区。北部洞口保留一条短径。
- 路线控制点、景物位置和朝向由编辑工具中的各区配置指定。工具加工地表坡度和材质过渡，并将结果保存到整岛专用地形资产。

00 为斜角总览，09 为正俯视。01–08 依次为沉船海滩、椰林海岸、西部森林、中央木桥、南部河口、东部林缘、北部山口和灯塔崖。

沉船海滩精修见 01、01-Beach-Camp 和 01-Beach-Route。沉船和补给件沿岸侧布置，营地放在另一侧，空地和北向主路留给角色通行。船体与补给件沿用 Kenney Pirate Kit，椰树沿用灯塔海岸资产，灌木与岩石沿用 Quaternius。破帆、布棚支撑、浅水浪边、贝壳和海星为本区新增的小型资产。[沉船海滩美术参考](../Standards/Shipwreck_Beach_Reference.png)

南部河口见 05、05-Estuary-Overview 和 05-Estuary-Banks。沿用木桥以东的南向支路，河道中心线及入海位置沿用全岛布局。植被、花草和岩石沿用 Quaternius Stylized Nature Mega Kit。睡莲、香蒲和局部河口水面为本区制作，潮间浪边复用海滩水面材质。[附件美术参考（图中标注为第 4 区）](../Standards/South_Estuary_Style_Reference.png)

东部林缘见 06、06-East-Fringe-Overview 和 06-East-Fringe-Uphill。沿现有道路布置入口野花坡、转弯岩台和北侧碎石坡，原林缘拱门点位改为自然岩组。树木、岩石和草花沿用 Quaternius Stylized Nature Mega Kit，岩台使用本区的暖灰、冷灰覆苔材质。[东部林缘美术参考](../Standards/East_Fringe_Reference.png)

北部岩石山地见 07、07-North-Mountain-Overview 和 07-North-Mountain-Overlook。八块主体巨石保留原定位，使用 Quaternius 岩石与松树模块。山口岩层材质与观景平台为本区制作。观景平台从东部林缘进山后的第一个转弯向山侧分出。[北部岩石山地美术参考](../Standards/North_Mountain_Reference.png)

东北灯塔崖见 08、08-Lighthouse-Ascent、08-Lighthouse-Terrace 和 08-Lighthouse-Seaward。沿用灯塔海岸的灯塔模型，悬崖及礁群沿用 Quaternius 岩石模块和北部山地的岩层材质。观景台从灯塔环路东侧进入，临海侧使用带碰撞的木质护栏。[东北灯塔崖美术参考](../Standards/Lighthouse_Headland_Reference.png)

### 沉船海滩的探索与资源

- 船边漂流木、近岸木桶和沉船背风侧木箱各可回收一次，分别提供 1、2、3 份木材。靠近后按 F。
- 在营火旁按 F 消耗一份木材，点亮营火三分钟。木材和容器状态随本次场景运行保存，重进场景会重置。
- 林缘阔叶树复用现有砍伐对象，靠近并面向树干按 E。
- 沉船、木桶、木箱和桅杆配件沿用 Kenney Pirate Kit，礁石及蕨类沿用现有岩石和植被资源。营火新增木架、吊锅、火光和火焰。
