# 灯塔海岸 · 场景与复用说明

场景：`Assets/Scenes/Lighthouse_Coast_ArtBenchmark_V01.unity`。使用项目现有 Unity 6000.6.9f1、Built-in 渲染管线。只包含灯塔海岸区域。

## 打开与游玩

在 Unity 中打开上述场景，点击 Play。W/S 或上下方向键前进、后退；A/D 或左右方向键转向。出生位置位于沙滩，沿浅色山路经中间平台到达灯塔前庭。角色仅用于行走与尺度检查，不是最终角色美术。

## 搭建方式

场景采用确定的位置、轮廓和路线。Blender 源文件保存独立的岩块、草冠、沙滩、道路、灯塔和建筑网格，Unity 中保存实际物体与碰撞；运行时不随机生成地形或散布物件。几何制作使用了建模辅助脚本，并非人工逐个顶点操作。源文件位于 `ArtSource/Lighthouse_Authored/Lighthouse_Coast_Authored.blend`。

1 Unity 单位为 1 米。通行道路约 3.3 米宽，外围草肩约 5.6 米宽。三层平台通过连续弯道连接。悬崖是独立网格组合，不依赖拉伸 Terrain。

## 模块复用

预制体位于 `Assets/Lighthouse_Authored/Prefabs`。

- `Cliff_0`—`Cliff_13`：独立岩块、草冠与不规则草沿组合。根节点位于岩块底部中心。旋转改变轮廓，允许少量非等比缩放；不同尺寸相互遮掩接缝，避免沿一条直线排成墙。不要把同一模块等距复制。
- 灯塔与看守人小屋应分别复用，先确定视觉中心，再以石平台衔接周围岩体；入口留出至少两米通行空间。
- 海边岩块适合放在浪线两侧，底部埋入沙地或水面，避免露出完整平底。
- 棕榈为本轮制作的连续弯曲树干与曲面叶片；阔叶树、灌木和草花来自已有资源包。植被按观景框景、路口提示、岩缝遮挡组织成簇，不能均匀铺满。
- 山路和海岸是本区域专用的轮廓资产。其他区域可沿用其宽度、材质过渡和支撑方式，但应重新设计路线，不能把完整地形模块平铺复制。

岩石使用世界坐标三向投射的手绘纹理；草地和沙地独立取样，路面两侧使用顶点权重过渡。纹理搭配低频色彩变化，不能只给不同地貌换颜色。水面包含深浅过渡与动态浪花，浪线距离与沙滩轮廓一致。

## 检查范围

已在 Unity Play Mode 中使用真实 CharacterController.Move 从沙滩沿全部路线节点移动到灯塔前庭，节点之间没有传送。结果和逐帧记录见上述检查文件。路径自动检查用于发现断路、碰撞阻挡和跌落，不代表覆盖玩家自由探索的每一种操作。

本场景的优化与接入仍需结合最终游戏的平台、相机、角色和性能预算进行；本轮没有执行目标设备性能验收。场景未接入其他地图区域。
